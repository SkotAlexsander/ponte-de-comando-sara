# P00 · Ponte de Comando · Sara

**O que é:** o programa do Alex para acompanhar e conversar com o Claude Code no PC dele. A conversa fica no centro, o mapa dos agentes fica no Fluxo, os números (tokens, limite, cache) ficam à vista, e a Sara fica numa miniatura sempre no canto, avisando quando o trabalho fica pronto ou quando precisa dele.

**Dono do código:** Davi (`eng-desktop`). **Dona da interface:** Sara, com a fonte em `00-empresa\corpos\sara\interface\estudio-local\`. **Checklist de referência:** `docs\pesquisa\rogerio-funcionalidades.md` (Heitor).

## Arquitetura

```
 Claude Code no terminal/VS Code ──hook──► ponte-hook.mjs ──POST 127.0.0.1:47615 + token──┐
 ~/.claude/sessions/*.json (busy→idle) ─────────────────────────────────────────────────────┤
 ~/.claude/projects/**.jsonl (tokens) ─── motor de tokens (Rust, thread própria) ───────────┤
 ~/.claude.json (limites 5 h / 7 d) ────────────────────────────────────────────────────────┤
                                                                                             ▼
                      casca Tauri 2 (Rust): estado da Sara · bandeja · notificação · pasta de trabalho
                                  │                              │
               sidecar Node (Claude Agent SDK) ◄──JSON/linha──►  │  eventos ponte:* ──► janelas
               uma query viva por conversa,                      │
               permissionMode 'default' + canUseTool             ├── carregamento (960×560, ≥ 8 s)
                                                                 ├── principal (Main ⇄ Fluxo)
                                                                 └── mini (sempre por cima, canto)
```

## Decisões tomadas

| # | Decisão | Por quê | O que faria mudar |
|---|---|---|---|
| D1 | **Tauri 2** | a máquina já tinha Rust MSVC, Build Tools, SDK do Windows e WebView2 (como no Valores); o executável é pequeno | precisar de algo que só o Electron dá |
| D2 | A interface é a **cópia** do protótipo da Sara (`ui\estudio\`), recopiada por `npm run sincronizar-ui` | a fonte é dela e muda; o programa não edita a origem | a Sara passar a gerar direto em `ui\` |
| D3 | Os dados reais entram por `window.ponte`, injetada em todas as janelas; um **adaptador provisório** liga o que o template ainda não chama; remendos de uma linha só na cópia | não editar a fonte da Sara e já ter o programa funcionando | o template chamar a ponte sozinho (cada parte do adaptador se desliga) |
| D4 | Conversa pelo **Claude Agent SDK oficial** num sidecar Node (decisão da Sara, 05/11) usando o `claude.exe` instalado (`pathToClaudeCodeExecutable`), SDK 0.3.318 = CLI 2.1.318 | cartão de permissão (`canUseTool`), parar sem perder (`interrupt`), trocar modelo e esforço no meio, retomar | o SDK mudar de termos ou deixar de funcionar com o login; aí sobra o modo `claude -p` que já existe |
| D5 | `permissionMode: 'default'` **sempre**, com `settingSources` do usuário, do projeto e locais | nunca agir sem aprovação (o Oficina vem ao contrário); valem `deny`, hooks e CLAUDE.md | o Alex pedir um modo explícito e visível |
| D6 | Node 24 da máquina é **pré-requisito**; o instalador leva o sidecar e o SDK (54 MB), mas não o Node | não embutir um runtime de 30+ MB e manter um só Node na máquina | instalar em PC sem Node |
| D7 | Servidor de hooks com `std::net`, só `127.0.0.1`, token aleatório de 32 bytes, recusa `Origin`, 64 KB, 3 s | sem dependência extra; o navegador não consegue mandar o cabeçalho do token sem pré-checagem | — |
| D8 | Miniatura: canto gravado + monitor; a janela tem o tamanho do conteúdo; não rouba o foco (`focusable(false)`); a cada 3 s reafirma "por cima" e devolve para dentro da área útil | fica no lugar mesmo com a barra de tarefas ou o monitor mudando | — |
| D9 | Motor de tokens portado do painel do Rogério (MIT, com aviso em `NOTICE.md`), com filtro de texto antes do JSON | transcripts de subagente passam de 1 GB | — |
| D10 | Custo sempre "**estimado**" | a tabela de preços (`precos.json` do Rogério, de 02/09/2026) não foi conferida contra a página da Anthropic; os modelos 5.5 não estão nela e aparecem como "preço desconhecido" (US$ 5/25) | conferir e atualizar a tabela |

## Riscos conhecidos

- O `status` `busy`/`idle` de `sessions/<pid>.json` existe nesta versão do CLI (conferido na máquina em 05/11), mas não é API documentada e pode mudar. Os hooks seguram o aviso se mudar.
- O adaptador da Main depende do formato do estado do protótipo (`extra`, `estado`, `rodandoEm`, `cfgs`, `abertas`, `novos`). Se a Sara mudar esses nomes, a parte correspondente cai de volta para o protótipo, sem quebrar a página.
- Os termos do SDK são da Anthropic ("SEE LICENSE IN README.md"). O instalador leva uma cópia para uso do Alex. **NÃO FOI POSSÍVEL VALIDAR** se dá para redistribuir para terceiros.
